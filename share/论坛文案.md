下载：见本帖附件（IdleAbyssMod-v1.6.1-share.zip），或者到仓库的 Releases 页下最新版。

这游戏前面玩着还行，一到刷王庭就难绷了，单人刷还限制周次数、刷出来还可能不是这角色要的，所以就让 AI 去除了限制，顺便补全了别的功能。

适用游戏版本 3.0.0（官方模组系统）

从 v1.0.0 起游戏自带模组加载器，这个 MOD 改成了标准模组包：不再修改 app.asar，也不用 Python 3，游戏更新 / Steam 校验也不会再把 MOD 冲掉。

安装（约 10 秒，不需要 Python）
1. 先启动一次游戏（进到标题页就行），让它建好存档目录，然后完全退出
2. 解压分享包，双击「安装.bat」——它会复制到
   %APPDATA%\IdleAbyssPrincesses\mods\chenxi_abyss_debug\
   第一次装 MOD、还没有 mods 文件夹的话，它会自己新建一个
3. 重启游戏，进到角色界面后按 F1（或点顶栏的「护肝」按钮）

卸载：双击「卸载.bat」，或者在游戏里 设置 → 模组 里停用 / 删除。删掉不影响存档。

几点说明

· 只要有一条「规则点」偏离默认值，Steam 成就就会暂停（游戏自己的规则）；纯改数值、改装备不碰规则点
· 联机（Steam 团本）时建议先关掉相关开关，免得数据不同步
· 改存档前请自行备份 %APPDATA%\IdleAbyssPrincesses\（游戏首次加载新模组时也会自动备份一份）
· 完整说明和更新记录见仓库里的 README 与 share/Mod修改内容说明.md
