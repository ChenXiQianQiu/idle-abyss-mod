# 深渊放置姬 · Mod 修改内容说明

## 当前包含的 Mod

### 深渊调试台（IdleAbyssMod）v0.3.2

游戏内按 **F1** 打开 / 关闭的调试面板，像素风界面与游戏本体一致，支持 `－/＋` 调整整个面板
（含文字）的缩放，标题栏可拖动。所有改动**即时写入存档**。

**资源页**

- 金币、魂晶（账号共用）、余烬之魂、秘境钥匙（上限 50）、扭蛋券、强化祝福、王庭锭、
  王庭碎片（普通 / 英雄 / 神话三档）
- 宝石库存：6 种宝石 × 5 个品级，逐格可改
- 每行支持「设为」「＋」（在当前值上加输入框里的数）「清零」，输入框支持 `1.5万` / `2亿` / `3k` 简写

**装备页**

- 列出已装备 / 背包 / 个人仓库 / 共用仓库的全部装备，可按来源筛选、按名称搜索。
  点选装备时只重画右侧编辑器，左侧列表的滚动位置不会跳回顶部
- 改品质（普通~套装）、上古、太古（太古会自动把所有词缀拉到满值）
- 改物品等级（新规则上限 100）、强化等级（0~15）
- 改基础数值：武器最小/最大伤害、护甲、副手加成、格挡，全部夹在游戏自己的掷点区间内
- 词缀：可增、删、改词条与数值。数值上限 = 该装备当前等级与品质下能掷出的最高值，
  超出会被自动夹住；词缀条数受品质与等级限制（与掉落规则一致）
- **「词缀全满」按钮**：一键把每一条可改词缀顶到区间上限，普通装备与王庭装备都有
  （王庭没有太古变体，靠这个按钮满值；王庭那条生命词条也会一起顶满）
- 镶嵌：给已有孔换宝石与品级，可在部位允许的上限内开孔
- 生成新装备：直接调用游戏自己的 `rollItem()`，产出的装备与正常掉落同规格，进背包并自动选中
- **王庭装备的品阶与「辉耀」**：王庭装 `r = 6`，在掉落体系里就是主线的**传奇（r=3）/ 套装（r=4）**
  那一档，用 `kind` 区分——`set` 是套装件（如「猩红誓约」），`leg` 是带王庭特效的传奇件
  （如武器「处刑」）。王庭没有上古 / 太古（`raidItemFix` 里硬写 `anc = false`），
  取而代之的是**辉耀（radiant）**，等价于主线的上古：
  - 面板上是一个「辉耀（数值 ×1.3）」开关，可自由开 / 关
  - 切换时四类数值一起变：基础值 ×1.3、随机词缀按掷点位置重算（上限 ×1.3，硬上限 ×1.25）、
    生命词条 ×1.3、◆ 特效词条按 `RAID_EFFECTS` 表重建（`raidItemFix`）
  - 来回切能完全还原（实测基础值与词缀差值为 0）
  - 装备副标题会写成「武器 · 王庭 · 传奇（处刑） · 辉耀 · ilvl 100」这种形式
- 王庭装备的品质按钮与基础数值仍然不开放手改（由品阶倍率决定）
- 王庭词缀区里两种「特殊行」的区别：
  - **◆ 开头的才是固定词条**（如 ◆ 暴击几率、◆ 技能伤害），值由 `RAID_EFFECTS` 表定义，
    读档时 `raidItemFix` 会整条重建，手改存不下来，所以只读
  - **生命词条不是固定词条**：它是王庭防具必带的一条普通词缀（装备卡上也没有 ◆），
    只是数值按王庭专用的 `RAID_LIFE_MUL` 公式掷、不适用主线 `life` 的区间。
    它和别的词缀一样有下拉框，可以换成任意合法词条，也可以删
  - 下拉框里有一个 **「生命·王庭」** 选项，选中就是把这条变成王庭生命词条
    （数值按 `RAID_LIFE_MUL` 算，比普通 life 大一个量级）。一件装备只能有一条，
    已有的时候其他行不会出现这个选项
  - 只有带 `RAID_LIFE_MUL` 的部位（护甲类、首饰）才有这个选项，武器 / 副手没有
- 奇物（r=5）只开放强化等级，避免破坏奇物表的语义

**进度页**

- 等级（1~70）、巅峰等级（新规则封顶 3000）、最高阶段（新规则封顶 101 / 旧规则无上限）、
  当前阶段、已解锁折磨档位、当前折磨档位、未分配属性点

**团本页（永夜王庭）**

- **必定掉落**（开关）：单人挑战每个首领保底掉 1 件王庭装备。
  游戏原本单人基础掉落 0 件、只有 20% 几率掉 1 件
  （`RAID_BAL.drops = { base: { 1: 0, ... }, extra: { 1: .2, ... } }`）。
  补出来的那件同样会参与女王的稀世判定（见下），所以开这个开关后
  女王的稀世概率从 20% × 1% = 0.2% 提到约 1%
- **只掉本职业 / 通用**（开关）：单人掉落池只留本职业装备与全职业通用首饰。
  游戏原版掉落池不按职业过滤（`raidLootTable` 只按首领筛），8 个职业混在一起，
  单人打本职业只占 1/8，掉到别职业的只能进账号共用仓库。
  开启后把掉落里别职业的装备换成同部位、本职业的版本（重新走 `raidRollItem` 生成，
  武器名 / 基础值 / 词缀池都跟着换），通用首饰与稀世原样保留。
  女王的首领池只有武器，过滤后只剩 1 件，所以掉的一定是本职业武器
- **无限掉落资格**（开关）：单人掉到装备也不消耗本周该首领的资格，可以一直刷
- **女王稀世概率**（数值）：直接改写 `RAID_BAL.relic`（原版 0.01），
  游戏自己的判定逻辑不用改就按新概率走。输入框可填任意百分比，
  另有 1% / 10% / 50% / 100% 四个快捷档；设为 100% 就是每次通关必掉永夜之心或女王的婚戒
- 以上三个开关 + 稀世概率都**只对单人挑战生效**，联机团本的掉落与资格完全走游戏原逻辑
- 通用首饰只挂在馆长 / 女官 / 园丁 / 守夜四个首领身上（与所属首领各约 50%）；
  门卫、宴主、女王原本就没有普通首饰。女王的池子只有 8 把武器 + 两件稀世，
  所以刷女王只会掉本职业武器，或按上面的概率换成稀世
- **女王稀世**：女王有掉落时把最后一件换成稀世（永夜之心 / 女王的婚戒，全职业通用）。
  原版单人只有 20% 掉 1 件，所以每次通关的稀世概率是 0.2%；开「必定掉落」后每次通关都掷
- 本周资格面板：三个难度 × 7 个首领，绿色 = 本周还能掉、灰色 = 已用掉
- 「重置本周资格（三档全清）」按钮：直接清空 `S.raid.cd`
- 开关与稀世概率都记在 `localStorage`（`iap-mod-prefs-v1`），重开游戏仍然有效

**其它**

- 面板位置与缩放记在 `localStorage`（`iap-mod-prefs-v1`），与游戏设置分开
- 面板打开时按键不会漏给游戏热键（在输入框里打数字不会切页）
- 启动时往游戏主进程日志写一行 `[IAP] 深渊调试台 v0.3.2 loaded`，方便排查「面板打不开」；
  某个页面渲染出错时也会把堆栈写进同一份日志，面板本身只显示一行占位提示

## 安装 / 卸载

```bash
# 构建 + 安装（首次会自动备份原始 app.asar 为 resources/app.asar.orig）
python scripts/mod_build.py --install

# 还原成原版
python scripts/mod_build.py --restore
```

Steam 校验游戏文件或游戏更新后 `app.asar` 会被覆盖，Mod 消失，重新执行 `--install` 即可。

### 2026-10-27（v0.3.2）

- 装备页：王庭的生命词条也能像其他词缀一样用下拉框换词条了
  - 之前生命行是纯文字标签（只能改数值），现在改成和上面几行一样的下拉框
  - 下拉框里多一个 **「生命·王庭」** 选项，等价于装备自带的那条王庭生命词条
    （数值走 `RAID_LIFE_MUL`，比普通 `life` 词缀大一个量级）
  - 换成普通词条时自动摘掉 `fixed` 标记、数值夹到新词条的合法区间；
    选回「生命·王庭」时重新挂上 `fixed`，数值夹到王庭生命区间
  - 一件装备只允许一条王庭生命：已有的时候其他行不出现这个选项，
    换到别的行时会自动清掉原来那条

    武器 / 副手选了会被拒绝并提示（游戏里它们的 `lifeMul` 为 0）
  - 词缀条数上限跟着变：有王庭生命时 4 条随机，卸掉后 5 条
- 顺带加固：下拉框被塞进不在词缀表里的值（空值 / 非法键）时直接忽略，不会把词条写成空
- 实测：护甲生命 3066 →（换成敏捷）69（区间 42~69）→（换回王庭生命）2606（区间 2606~3526）
  → 再换回敏捷 69，`fixed` 标记正确增删；武器选「生命·王庭」被拒绝，数值未被破坏；
  「词缀全满」仍把 5 条（含王庭生命 3526）全部顶到上限

### 2026-10-27（v0.3.1）

- 修：装备页点选列表靠下的装备时，左侧列表的滚动条会直接跳回顶部。
  原因是点选走整页重绘，列表 DOM 被重建、滚动位置归零。现在点选只重画右侧编辑器
  （`selectItem`，列表 DOM 复用、滚动位置原样保留），并且面板重绘时统一记录 / 还原
  `.iap-body` / `.iap-eqitems` / `.iap-eqed` 三个滚动容器，改数值、切筛选也不会跳

- 修：王庭词缀区的标注语义错了。王庭**生命词条不是固定词条**——它是王庭防具必带的
  一条普通词缀（装备卡上也没有 ◆），只是数值按 `RAID_LIFE_MUL` 公式掷。
  真正由装备表定义、读档会被 `raidItemFix` 重建的**固定词条是 ◆ 开头的那几条**
  （如 ◆ 暴击几率、◆ 技能伤害）
  - 生命词条：去掉 ◆ 前缀与「固定」字样，改标「王庭生命词条 · 区间按王庭生命公式」，
    数值可改、**也可以删**
  - ◆ 词条：标注改为「固定词条 · 由装备表定义 / 读档时游戏会重建，手改存不下来」
- 改：移除团本页的「女王也掉通用首饰」开关。女王保持原版掉落构成（8 把本职业武器），
  只保留**稀世概率**设置；区块标题改为「女王稀世」
