# 深渊放置姬 · 代码索引文档

> 本项目的「反编译」= 解包 Electron 的 `resources/app.asar`。游戏不是 Unity 工程，
> 没有程序集、没有 Cpp2IL / dnSpy 可用的东西，全部逻辑都是 `web/js/*.js` 里的普通
> 经典脚本（classic script，顶层 `const` / `function` 共享同一个全局作用域）。
>
> 解包命令（工具：`scripts/asar_extract.py`，纯 Python 实现，不依赖 npm）：
>
> ```bash
> python scripts/asar_extract.py resources/app.asar .tools/asar_extracted
> ```
>
> `.tools/asar_extracted/` 只用于阅读和定位注入点，**不入库、不修改**。

## 一、应用整体结构

```
resources/app.asar
├─ package.json            name/version/main = electron/main.js
├─ electron/
│  ├─ main.js              主进程：窗口、托盘、存档读写 IPC、Steam 联机（893 行）
│  ├─ preload.js           contextBridge 暴露 window.desktop（沙盒 + contextIsolation）
│  └─ assets/              图标、托盘图
└─ web/                    渲染层 = 整个游戏
   ├─ index.html           640×360 固定逻辑分辨率，按 --z 整数缩放
   ├─ css/ui.css           像素风主题（石框 + 铜钉 + 鎏金）
   ├─ fonts/               Ember Pixel 像素字体
   ├─ assets/              立绘、音乐、音效（99 MB，manifest.js 索引）
   ├─ heroes/              每个职业一个文件
   └─ js/                  游戏逻辑（见下表）
```

关键点：

- **存档不在 asar 里**，在 `%APPDATA%/IdleAbyssPrincesses/`（`save.json` = 1 号位、
  `save_2..10.json` = 其他位、`account.json` = 账号级数据、`prefs.json` = 设置）。
  渲染层通过 `window.desktop.loadSync/saveSync/accLoadSync/accSaveSync` 走 IPC 落盘，
  没有 `window.desktop`（网页版）时退回 `localStorage`。
- 出厂包 `config.js` 里 `DEV_BUILD = false`，所以 `?debug`（`window.__ember` 作弊 API）
  在正式版里不存在——这也是本 Mod 需要自己注入脚本的原因。
- `web/js/*.js` 全部是经典脚本，**加载顺序即依赖顺序**（见 `index.html` 底部）。
  任何一个脚本的顶层 `const` 对其他脚本可见，Mod 脚本因此可以直接按名字读 `S` / `A`。

### item 对象

```js
{
  id, cls, t,          // 唯一 id、职业、部位（weapon/offhand/helm/.../ring/amulet）
  r,                   // 品质 0 普通 1 魔法 2 稀有 3 传奇 4 套装 5 奇物 6 王庭
  ilvl, plus,          // 物品等级、强化等级（0..15）
  anc, primal,         // 上古（×1.3）、太古（词缀满值，且必然 anc）
  name, bname,         // 显示名 / 底材名
  min, max,            // 武器伤害（二者比例 3:5）
  armor, block, imp,   // 护甲 / 格挡 / 副手加成 {k, v}
  aff: [{ k, v, q }],  // 词缀：键、数值、掷点位置 0..1
                       //   额外标记：fixed=1 → 王庭固定生命词条；raid=1 → 王庭特效词条
  leg, set,            // 传奇特效键 / 套装键
  sock: [null|{g,q}],  // 镶嵌孔：宝石键 + 品级
  odd,                 // 奇物键（奇物才有）
  raid, raidDiff, ...  // 王庭装备才有；radiant = 辉耀（词缀 ×1.3、上限 ×1.25）
}
```

### 数值区间（「合理范围」的定义）

- 词缀：`affRange(k, ilvl, it)`（`items.js:57`）
  `top = AFF[k].f(ilvl) × (r>=3 ? 1.1 : 1) × (anc ? 1.3 : 1)`，
  `cap = AFF[k].cap × (anc ? 1.25 : 1)`，返回 `[min(top*.6, cap), min(top, cap)]`。
- 王庭词缀：`raidRollAff`（`raid_items.js:292`）——`top = AFF[k].f(ilvl) × 1.1 × (radiant ? RAID_ITEM_BAL.radiantMul : 1)`，
  `cap = AFF[k].cap × (radiant ? 1.25 : 1)`。**`radiantMul` 实际值是 1.3**（`raid_items.js:14`）。
- 王庭固定生命词条（`raid_items.js:339`，带 `fixed:1`）不走 `affRange`，掷点是
  `RAID_LIFE_MUL[部位] × raidItemLifePower(难度, 职业) × P(ilvl) × rnd(.85, 1.15) × radiantMul`，
  区间取 `rnd` 的上下界。最终生效时还要再乘 `RAID_ITEM_BAL.lifeMul`（=20，`raidAffixMul`）。
- 王庭特效词条（`raid:1`）的值 = `RAID_EFFECTS[id].st[k] × radiantMul`，**由表定义、不是掷点**；
  读档时 `raidItemFix` 会把它们整条过滤掉再重建（`raid_items.js:380-383`），所以手改存不下来。
- 基础数值：`rollItem` 里 `4 × P(ilvl) × rnd(.85, 1.15) × rm`，`rm = 品质倍率 × 上古 × 太古`，
  武器 `min = a×.75 / max = a×1.25`，护甲 `ARMOR_W[t] × 3 × P(ilvl) × rnd(.85,1.15) × rm`。
- 词缀条数上限：主线 `[0, 2, 4, 4, 4][r] + (r>=3 && ilvl>=40 ? 1 : 0)`；
  王庭 `RAID_ITEM_BAL.affixes - (有固定生命词条 ? 1 : 0)`（`raid_items.js:332`），
  即武器 5 条、护甲类与首饰 4 条随机 + 1 条固定生命。

### 团本掉落与掉落资格

- **掉落件数**（`raid_ui.js:1133` `raidDevRollDrops`，联机同名逻辑在 `raid_net.js:898`）：
  ```js
  let n = RAID_BAL.drops.base[teamSize] || 0;          // { 1:0, 2:0, 3:1, 4:1 }
  if (rng() < RAID_BAL.drops.extra[teamSize]) n++;     // { 1:.2, 2:.5, 3:.5, 4:.5 }
  ```
  单人 `teamSize = RAID_BAL.solo.size = 1` → **基础 0 件、20% 几率 +1 件**。
  件数确定后从 `raidLootTable(bossId)` 里随机挑 id，再 `raidRollItem(id, diff, rng)` 生成。
- **掉落资格**：`S.raid.cd[`${diff}:${boss}`]`，判定 `raidHasCD`，写入 `raidUseCD`（`raid_items.js:461-471`）。
  单人流程（`raid_ui.js:951-961`）：`had = raidHasCD(...)` → 没资格就不掷掉落 → 掉了才 `raidUseCD`。
- **周刷新**：`raidWeekSync`（`raid_items.js:451`）在 `S.raid.week !== 当前周种子` 时清空 `cd` / `att` / `conv`，
  由 `raidWeekCheck` 在大厅、单人面板、开打前各调一次。
- 联机掉落资格走 `raid_auction` 的 `eligible` 字段，与单人共用同一份 `S.raid.cd`。

## 四、Mod 注入点

`web/index.html` 的 `</body>` 之前插入一段：

```html
<!-- ===== IAP Mod begin ===== ... -->
<link rel="stylesheet" href="css/mod_panel.css">
<script src="js/mod/mod_util.js"></script>
<script src="js/mod/mod_resources.js"></script>
<script src="js/mod/mod_equip.js"></script>
<script src="js/mod/mod_progress.js"></script>
<script src="js/mod/mod_panel.js"></script>
<script src="js/mod/mod_boot.js"></script>
<!-- ===== IAP Mod end ===== -->
```

放在 `main.js` **之后**，因为 `main.js` 在解析期就会跑 `load()` / `refreshStats()`，
Mod 需要 `S`、`A`、`AFF`、`affRange` 等已经就绪。
